# Cross-Link & Referencing Protocol

Panduan format penulisan link antar file di Academic OS:

- **Wikilinks (Direkomendasikan):** `[[folder/subfolder/nama-file]]`
  Contoh: `[[courses/STA501/lecture-01]]` atau `[[knowledge/concepts]]`
- **Markdown Links Standar:** `[Label Relatif](../path/ke/file.md)`
  Contoh: `[CatBoost Paper](../../research/papers/catboost-paper.md)`
