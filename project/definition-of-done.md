# Definition of Done (DoD)

Setiap issue, fitur, atau catatan baru dianggap **SELESAI (Done)** hanya jika telah memenuhi checklist berikut:

- [ ] **File Dibuat & Lokasi Sesuai:** Dokumen atau script berada di direktori yang benar sesuai hierarki repositori.
- [ ] **Struktur & Frontmatter Valid:** Memuat metadata YAML frontmatter standar di baris teratas.
- [ ] **Cross-Linked:** Memiliki minimal 1 tautan rujukan (\[[...]]\) ke konsep, metode, atau mata kuliah terkait.
- [ ] **Tested / Verified:** Kode atau sintaks markdown telah diuji tanpa error (eksekusi CLI atau render editor).
- [ ] **Committed & Pushed:** Perubahan telah dicatat via Git commit yang deskriptif dan disinkronkan ke remote repository.
- [ ] **Dokumentasi & Dashboard Terupdate:** Status pada \acklog.md\ atau \dashboard/progress.md\ telah diperbarui.
