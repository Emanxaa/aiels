# Lecture Process

Instruksi Kerja:
1. Minta atau baca catatan kuliah mentah yang diberikan user beserta kode mata kuliahnya (misal: STA501, STA511, STA561, STA581).
2. Gunakan format dari `templates/lecture.md`.
3. Hasilkan file catatan di `courses/<KODE_MK>/lecture-<nomor>.md` yang wajib memuat:
   - Ringkasan
   - Konsep Inti
   - Rumus / Notasi Matematis (gunakan LaTeX jika ada formula)
   - Recall Card (Active Recall Q&A)
   - Latihan Soal Mandiri
4. Perbarui file jurnal harian hari ini di `journal/daily/` pada bagian aktivitas/pembelajaran.
