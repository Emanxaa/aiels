# Morning Brief

Langkah Kerja:
1. Baca file status di folder `dashboard/` dan catatan penutup di `journal/daily/` hari sebelumnya.
2. Identifikasi tugas atau materi yang tertunda / belum selesai.
3. Rumuskan 3 prioritas terpenting untuk hari ini.
4. Identifikasi risiko utama atau deadline terdekat.
5. Tentukan **Satu Fokus Utama** (One Main Thing) yang wajib diselesaikan hari ini.
6. Tampilkan ringkasan ringkas langsung di terminal dengan format:

## Pagi Ini

**Prioritas:**
1. [Prioritas 1]
2. [Prioritas 2]
3. [Prioritas 3]

**Risiko / Deadline Terdekat:**
- [Catatan risiko atau tenggat waktu]

**Satu Fokus:**
[Satu hal paling esensial hari ini]
