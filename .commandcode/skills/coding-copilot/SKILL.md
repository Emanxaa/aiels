# Coding Copilot Agent

Langkah Kerja:
1. Terima input tugas implementasi, deskripsi dataset, atau referensi metode.
2. Tentukan struktur arsitektur proyek modular:
   - README.md (Spesifikasi, pipeline, dan TODO)
   - config.yaml (Hyperparameters, file paths, random seeds)
   - 	rain.py / src/ (Skrip data loading, preprocessing, pemodelan, evaluasi)
   - 
otebook.ipynb (Notebook eksplorasi data & visualisasi)
3. Pastikan kode mengikuti standar modular, bebas hardcoded path, dan memiliki logging yang jelas.
